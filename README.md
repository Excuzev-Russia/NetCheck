# NetCheck — проверка доступа + тест скорости

Приложение на Python (Kivy) для Android:

- **Вкладка «Сайты»** — проверяет Ozon, Max, Yandex, VK и показывает:
  «Нет связи» / «Нет доступа» / «Есть доступ».
- **Вкладка «Скорость»** — провайдер, регион, пинг, скорость загрузки и отдачи.

## ⚠️ Важно: APK нужно собрать самостоятельно

Я не могу скомпилировать готовый `.apk` внутри этого чата: сборка Android-приложения
требует Android SDK/NDK (несколько гигабайт) и доступа в интернет для их скачивания,
а моя рабочая среда изолирована и без сети. Поэтому здесь — **полный исходный код
и конфиги**, готовые к сборке. Есть два способа получить APK, оба ниже.

## Файлы в архиве

```
netcheck_apk/
├── main.py              — экраны и логика (переключение вкладок, потоки)
├── netutils.py           — сетевые проверки и замеры скорости
├── netcheck.kv           — внешний вид (тёмная тема, вёрстка)
├── buildozer.spec        — конфиг сборки APK (permissions, версия Android и т.д.)
├── requirements.txt       — зависимости для локального запуска на компьютере
├── .gitignore
└── .github/workflows/build-apk.yml — автосборка APK в облаке (GitHub Actions)
```

## Способ 1 (проще всего): GitHub Actions — без своего компьютера

1. Создайте новый репозиторий на GitHub и загрузите туда содержимое этой папки
   (просто перетащите распакованные файлы через веб-интерфейс GitHub).
2. Откройте вкладку **Actions** в репозитории — сборка запустится автоматически
   (или нажмите «Run workflow» вручную).
3. Через 10–20 минут в разделе **Actions → последний запуск → Artifacts**
   появится `netcheck-apk` — скачайте и распакуйте, внутри `.apk`.
4. Скопируйте `.apk` на телефон и установите (потребуется разрешить установку
   из неизвестных источников в настройках Android).

## Способ 2: сборка на своём компьютере (Linux / WSL)

```bash
pip install buildozer cython
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool pkg-config
buildozer android debug
```

Готовый файл появится в `bin/netcheck-0.1-debug.apk`. Первая сборка долгая
(20–40 минут) — buildozer сам скачает Android SDK/NDK.

## Проверить логику на компьютере перед сборкой (необязательно)

```bash
pip install -r requirements.txt
python main.py
```

Откроется то же самое окно, что будет и на телефоне — удобно для отладки
без пересборки APK каждый раз.

## Как считаются статусы

- **Нет связи** — не удалось подключиться ни к одному нейтральному серверу
  (Cloudflare 1.1.1.1, Google DNS 8.8.8.8) → на устройстве нет интернета вообще.
- **Нет доступа** — интернет есть, но конкретный сайт не отвечает (таймаут/обрыв).
- **Есть доступ** — сайт ответил (даже кодом ошибки — значит, до него дошли).

Это эвристика, а не официальный способ определить блокировку: отличить
«заблокировано провайдером» от «сайт временно не работает» напрямую с телефона
невозможно — оба случая выглядят как обрыв соединения.

## Изменить список сайтов или домены

Откройте `main.py`, список `SITES` в начале файла — добавляйте/меняйте
name / domain / url по своему усмотрению.
